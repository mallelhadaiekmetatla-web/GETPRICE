# PriceScan — منصة البحث عن أسعار المنتجات

منصة عربية متجاوبة لمسح الباركود بكاميرا الهاتف والبحث عن اسم المنتج وسعر البيع في ملف Excel. مناسبة للنشر المجاني عبر GitHub Pages.

## الملفات
- `index.html` — الواجهة.
- `style.css` — التصميم المتجاوب وبطاقات Gradient.
- `app.js` — قراءة Excel والبحث وتشغيل الكاميرا.
- `data/products.xlsx` — قاعدة بيانات المنتجات.

## تنسيق Excel
يجب أن يحتوي الصف الأول على الأعمدة التالية بالضبط:
- `CODE BARRE`
- `DESIGNATION`
- `PRIX DE VENTE`

مثال:
| CODE BARRE | DESIGNATION | PRIX DE VENTE |
|---|---|---:|
| 6130000000012 | مثال منتج | 125.00 |

**مهم:** اجعل عمود `CODE BARRE` في Excel من النوع **Text / Texte** حتى لا تضيع الأصفار الموجودة في بداية الكود.

## نشر المنصة على GitHub Pages
1. أنشئ مستودعاً جديداً على GitHub أو استخدم مستودعك الحالي.
2. ارفع محتويات هذا المجلد، وليس ملف ZIP فقط، إلى جذر المستودع.
3. افتح `Settings` ثم `Pages`.
4. في `Build and deployment` اختر `Deploy from a branch`.
5. اختر `main` و`/(root)` ثم `Save`.
6. انتظر اكتمال النشر وافتح رابط GitHub Pages عبر HTTPS.
7. على الهاتف، افتح الرابط واسمح باستخدام الكاميرا.

## تحديث الأسعار
1. عدّل `data/products.xlsx` في Excel.
2. حافظ على أسماء الأعمدة الثلاثة.
3. ارفع النسخة الجديدة إلى GitHub بنفس المسار.
4. انتظر إعادة النشر ثم أعد تحميل الصفحة.

## ملاحظات تقنية
- تحتاج قراءة ملف Excel إلى اتصال بالإنترنت لتحميل مكتبة SheetJS من CDN.
- تحتاج الكاميرا إلى HTTPS أو `localhost` وإذن من المستخدم.
- هذه النسخة للبحث العام فقط، ولا تحتوي على تسجيل دخول أو لوحة إدارة.
- كل زائر يستطيع قراءة ملف الأسعار المنشور؛ لا تضع بيانات سرية في الملف.
- إن كان المستودع الحالي يستخدم `server.js` وSupabase، فهذه نسخة مستقلة ثابتة لا تستبدل ملفات الخادم تلقائياً.
